# კონტენტის შევსების შაბლონები

ოთხი CSV ფაილი — თარიღები უკვე ჩაწერილია, შენ მხოლოდ ტექსტი უნდა შეავსო.
პროექტი: https://supabase.com/dashboard/project/cnfpgzhdqjntvakisgvn

## როგორ შეავსო

1. **გახსენი Google Sheets-ით** (File → Import → Upload).
   Excel-ში ორმაგი დაწკაპუნებით გახსნისას ქართული ასოები შეიძლება აირიოს —
   თუ Excel გინდა: Data → From Text/CSV → Encoding: **UTF-8**.
2. შეავსე სვეტები (ცარიელი უჯრა = ბაზაში ცარიელი მნიშვნელობა, პრობლემა არ არის).
3. ჩამოტვირთე ისევ CSV-ად (File → Download → Comma Separated Values).
4. Supabase → **Table Editor** → აირჩიე ცხრილი → ზემოთ **Insert → Import data from CSV**
   → ატვირთე ფაილი → Import.

> **მნიშვნელოვანი:** იმპორტი **ამატებს** სტრიქონებს. თუ ერთი და იგივე თარიღი ორჯერ ატვირთე,
> `daily_history`-ში შეცდომას მოგცემს (თარიღი უნიკალურია) — ეს კარგია, დუბლიკატს არ გაგიშვებს.
> `science_events`/`medicine_events`-შიც თითო დღეზე მხოლოდ ერთი ჩანაწერი შეიძლება.
> ნაწილ-ნაწილ ატვირთვა შეიძლება: ჯერ იანვარი, მერე თებერვალი და ა.შ.

## 1. `daily_history.csv` — მთავარი ეკრანი (366 სტრიქონი მზადაა)

| სვეტი | რა იწერება | სად ჩანს აპში |
|---|---|---|
| `date` | **ნუ შეეხები** — `MM-DD` ფორმატში უკვე ჩაწერილია | — |
| `georgia_content` | საქართველოს ისტორია ამ დღეს | **მთავარი ეკრანი** (ისტორია ტაბი) |
| `world_content` | მსოფლიო მოვლენები ამ დღეს | ბარათი „მსოფლიო ისტორია" |
| `births_content` | ვინ დაიბადა/გარდაიცვალა ამ დღეს | ბარათი „პიროვნებები" |

ტექსტი თავისუფალი სიგრძისაა, აბზაცებიც შეიძლება. **რიცხვები ავტომატურად ოქროსფრად გამოიყოფა**
მთავარ ეკრანზე (მაგ. წლები), ანუ ცალკე ფორმატირება არ გჭირდება.

მაგალითი:

```
date,georgia_content,world_content,births_content
11-07,"1918 წელს საქართველოში...","1917 წელს...","ამ დღეს დაიბადა..."
```

## 2. `science_events.csv` — მეცნიერება ტაბი (366 სტრიქონი მზადაა)

| სვეტი | რა იწერება |
|---|---|
| `month`, `day` | **ნუ შეეხები** — უკვე ჩაწერილია |
| `year` | წელი, მაგ. `1903` (მხოლოდ რიცხვი) |
| `title` | აღმოჩენის სათაური, მაგ. `პირველი ფრენა` |
| `description` | აღწერა, ვრცლად |

## 3. `medicine_events.csv` — ბარათი „მედიცინის მატიანე"

იგივე სტრუქტურა, რაც მეცნიერებას.

## 4. `quiz_questions.csv` — ქვიზი

| სვეტი | რა იწერება |
|---|---|
| `month`, `day` | რომელი დღის კითხვაა |
| `category` | სურვილისამებრ, მაგ. `ისტორია` (ბარათზე ჩანს) |
| `question` | კითხვა |
| `option1`–`option4` | ოთხი ვარიანტი |
| `correct` | **ზუსტად იგივე ტექსტი**, რაც სწორ ვარიანტშია — სიმბოლომდე |

აპი დღეში **4 კითხვას** იღებს, ანუ თითო დღეზე 4 სტრიქონი ჯობია.
ფაილში ერთი ნიმუშია — წაშალე და შენი ჩაწერე.

⚠️ `correct`-ში ასოების/ინტერვალის ოდნავი სხვაობაც კი გამოიწვევს, რომ **სწორი პასუხი
არასდროს ჩაითვალოს სწორად**. ყველაზე უსაფრთხოა ვარიანტის უჯრიდან კოპირება.

## სად რა გამოჩნდება — მოკლედ

- `daily_history` ცარიელია იმ დღეს → მთავარ ეკრანზე: „ინფორმაცია ამ დღისათვის ჯერ არ არის დამატებული"
- `science_events`/`medicine_events` ცარიელია → „ამ დღეს ჩანაწერები არ მოიძებნა"
- `quiz_questions` ცარიელია → „დღევანდელი ქვიზი მზადდება..."

ანუ ნაწილობრივ შევსებაც შეიძლება — აპი არ გატყდება, უბრალოდ იმ დღეს ცარიელ მდგომარეობას აჩვენებს.
