# კონტენტი

`daily_history.json` — 366 დღის ისტორიული ტექსტი, აწყობილი **ქართული ვიკიპედიის**
დღის გვერდებიდან (`1 იანვარი` … `31 დეკემბერი`; განყოფილებები: დღის მოვლენები,
ამ დღეს დაბადებულნი, ამ დღეს გარდაცვლილნი).

თითო ჩანაწერი:

| ველი | შიგთავსი | სად ჩანს |
|---|---|---|
| `date` | `MM-DD` | — |
| `georgia_content` | ჯერ ქართული მოვლენები, მერე მსოფლიო (≈5) | მთავარი ეკრანი |
| `world_content` | დარჩენილი მოვლენები (≈10) | „მსოფლიო ისტორია" |
| `births_content` | დაიბადნენ (6) + გარდაიცვალნენ (4) | „პიროვნებები" |

## ბაზაში ჩაწერა

```
$env:SUPABASE_SERVICE_ROLE_KEY="<service_role key>"; node scripts/import-content.js
```

სკრიპტი აკეთებს upsert-ს `date`-ის მიხედვით, ანუ ხელახლა გაშვება უსაფრთხოა —
არსებულ სტრიქონებს განაახლებს, დუბლიკატს არ შექმნის.

ეს ფაილი იმავდროულად **სარეზერვო ასლია**: თუ ბაზა დაიკარგა, ერთი ბრძანებით აღდგება.
