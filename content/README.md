# კონტენტი

`daily_history.json` — 366 დღის ისტორიული ტექსტი, აწყობილი **ქართული ვიკიპედიის**
დღის გვერდებიდან (`1 იანვარი` … `31 დეკემბერი`; განყოფილებები: დღის მოვლენები,
ამ დღეს დაბადებულნი, ამ დღეს გარდაცვლილნი).

თითო ჩანაწერი:

| ველი | შიგთავსი | სად ჩანს |
|---|---|---|
| `date` | `MM-DD` | — |
| `georgia_content` | ჯერ ქართული მოვლენები, მერე მსოფლიო (≈5) | მთავარი ეკრანი |
| `world_content` | დარჩენილი მოვლენები (≈10) | „მსოფლიო ისტორია" |
| `births_content` | დაიბადნენ (6) + გარდაიცვალნენ (4) | „პიროვნებები" |

## ბაზაში ჩაწერა

```
$env:SUPABASE_SERVICE_ROLE_KEY="<service_role key>"; node scripts/import-content.js
```

სკრიპტი აკეთებს upsert-ს `date`-ის მიხედვით, ანუ ხელახლა გაშვება უსაფრთხოა —
არსებულ სტრიქონებს განაახლებს, დუბლიკატს არ შექმნის.

ეს ფაილი იმავდროულად **სარეზერვო ასლია**: თუ ბაზა დაიკარგა, ერთი ბრძანებით აღდგება.

## გვარები — `surnames.json`

წყარო სხვაა: გვარების ტექსტები **gvarigen.ge-ის ბაზაში** (საიტის Supabase პროექტი)
იწერება ხელით, აპი კი მათ იმპორტით იღებს:

```
node scripts/import-surnames.js              # ჩამოტანა + გასუფთავება + ატვირთვა
node scripts/import-surnames.js --dry-run    # მხოლოდ JSON-ის გადაწერა
node scripts/import-surnames.js --from-json  # ატვირთვა არსებული JSON-იდან
```

სჭირდება `.env.local`-ში ორი გასაღები: `SUPABASE_SERVICE_ROLE_KEY` (აპის პროექტი)
და `GVARIGEN_SERVICE_ROLE_KEY` (საიტის პროექტი).

| ველი | შიგთავსი |
|---|---|
| `surname` | გვარი — ძებნის გასაღები, უნიკალური |
| `crest_code` | `GRB-NNN` → `gvarigen.ge/gvari/<crest_code>` |
| `preview` | ისტორიის პირველი 42 სიტყვა |

`full_history` იმავე ნაწყვეტის ასლით ივსება — 2026-11-14-მდე აწყობილი ბილდები
